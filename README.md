2. Deskripsi Proyek

Proyek ini bertujuan untuk menganalisis karakteristik data dan memperkirakan kebutuhan penyimpanan (storage) pada sistem peta dan ulasan warung kuliner di Denpasar.

Data yang dianalisis meliputi ulasan pelanggan, foto makanan dan warung, titik lokasi warung, serta catatan menu. Analisis dilakukan menggunakan Python dan library Pandas untuk mengolah data, menghitung estimasi ukuran penyimpanan, serta memperkirakan pertumbuhan data selama 12 bulan.

3. Tujuan

Mengidentifikasi jenis data yang dibutuhkan dalam sistem peta dan ulasan warung kuliner.

Menganalisis format, atribut teknis, variasi, dan metadata setiap jenis data.

Menghitung estimasi kebutuhan penyimpanan pada bulan pertama.

Memperkirakan kebutuhan penyimpanan selama 12 bulan dengan asumsi pertumbuhan data sebesar 10% per bulan.

Menambahkan cadangan penyimpanan sebesar 30% dari estimasi akumulasi data tahunan.

Menyimpan hasil analisis dalam format CSV agar dapat digunakan kembali. 

 4. Asumsi Perhitungan Storage

      Perhitungan menggunakan asumsi berikut:

      Data bulan pertama merupakan dasar estimasi.

      Data baru bertambah sebesar 10% setiap bulan.
    
      Periode estimasi adalah 12 bulan.

      Cadangan penyimpanan sebesar 30% ditambahkan pada estimasi akumulasi data selama 12 bulan.

      Konversi ukuran menggunakan 1 MB = 1.024 KB dan 1 GB = 1.024 MB.
